# 目的

ある部門で必ず起動する必要のある複数のアプリケーションを重複起動しないように確認しつつ一括で起動するランチャーアプリ
機能は単純なのでPowerShellとxamlのUIデザインでできるかと思います。

# 機能

- Windowは最大化とアイコン化の2つのモード。最大化しているときは背景透過60%。

- 起動するアプリケーションのリストは外部JSONファイルで定義、ランチャーへはオプションで指定

	- JSON は `Name` と `Path` を基本とし、必要に応じて `ProcessNames`（文字列配列）を指定可能
	- 起動時に渡すコマンドラインオプションは `Arguments`（文字列または文字列配列）で指定可能
	- 後方互換として `CommandLineOptions`（文字列または文字列配列）も受け付けます
	- `ProcessNames` 未指定時は `Path` の実行ファイル名で起動判定
	- `Arguments` / `CommandLineOptions` が指定されている場合は、プロセス名に加えてコマンドライン引数も一致したときのみ「起動中」と判定
	- 例: `calc.exe` のように実際のプロセス名が異なる場合は `"ProcessNames": ["CalculatorApp"]` を指定

- 画面はWindows8のタイルよろしく4x3, 4x4, 5x4 の分割パターンで構成 設定ファイルにあるアプリケーションの数で適切に変化します

- 各タイルにアプリケーションのアイコンがあればアイコンを拡大してタイルの中央上側60%で表示、中央寄せ下には設定ファイルに記載されたアプリケーション名を表示します

- 実行状況をタイルの背景色で表示します タイルに割り当てられたアプリケーションが起動しているときはグリーン 起動していないときは赤 実行ファイルの存在が確認できない場合はグレーとアイコン部分にエラーアイコンを表示します

- 起動状態はプロセスを取得して確認します、アプリケーションの重複起動は許可されません

- ランチャーを起動して1秒後に設定されたアプリケーションをすべて起動します

- 起動していないタイルをクリックした場合 アプリケーションを起動します

- ウインドウの更新は操作を行ったあとは1秒ごとに、全体の状態が10秒以上変化がなければ更新を停止します。その後はウインドウがアクティブになったとき、もしくはF5キーが推されたときに行います。 

- 全画面表示ではなく、終了と最小化がしやすいようにウインドウ形式のアプリです
